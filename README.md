# Mealio

Mobile-first, single-owner meal tracker. Planning and visual references stay in the parent `plan/` directory outside this Git repository.

The homepage currently shows an interactive **sample-data preview**, not a private tracker. No server-side meal data or account is connected yet. Do not deploy for real meal history.

Use Node 20.11+. Run `npm install`, `npm run dev`, `npm run lint`, `npm run typecheck`, and `npm test`. The `.env.example` file lists future private settings; never commit filled-in credentials.
